# 购买判断卡

可以复制这张卡到自己的笔记。不要将含姓名、住址、健康资料、账单或账号的版本上传到公开仓库。

- 想买什么：
- 它解决的具体问题：
- 最近实际发生过的例子与频率：
- 不买、维修、借用或继续使用旧物的办法：
- 预定比较的使用期间：
- 买价（同一货币单位）：
- 期间订阅、耗材、能源、维修和其他费用（同一货币单位）：
- 保守转售收入（不确定则填0）：
- 总成本（同一货币单位）：
- 预计使用次数，以及次数减半的情况：
- 设置、学习、沟通、维护时间：
- 预期改善，以及怎样观察它是否发生：
- 是否影响必要生活支出或已有付款义务：
- 若预计使用次数减半、后续费用增加，决定会不会改变：
- 需核查的当地税费、保修、退改、维修与软件支持：
- 是否有隐私、安全、合约或资格问题需要先核查：
- 决定：购买／小额试用／延后／不买。
- 复查日期与结果：

## 三个有用的算式

总成本＝买价＋使用期间其他费用－保守转售收入。

单次成本＝总成本÷实际或保守预计使用次数。次数为零时不要计算，直接记为“未使用”。

每省一小时的增量成本＝相对替代方案多付的钱÷净省时间。若没有净省时间，就不用这个指标；舒适和喜欢可以另作判断。

家电简单回本期＝额外购置成本÷每年净节省费用。仅当净节省为正时有意义；还需要考虑寿命、维修、能源价格变动和原本是否需要更换。

不要把健康、陪伴或舒服硬换成统一分数。算式帮助比较相近方案，最后仍要结合预算和个人偏好。
