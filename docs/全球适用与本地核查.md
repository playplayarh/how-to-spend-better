# 全球适用与本地核查

本版研究范围面向全球。它使用国际公共卫生资料、不同国家的研究与官方说明，不以某一个国家的消费价格作为标准。全球范围检索也不代表研究覆盖或代表了每个国家。

## 可以迁移的方法

明确问题；计算同一期间的总成本；保守估计使用；检验替代办法；考虑退出；购买后复查。所有算例都假设使用同一种货币，数字仅演示关系，不能比较不同国家的购买力。

## 购买前要在所在地核查的六件事

1. 最终费用：税费、运费、关税、汇率手续费与分期费用。
2. 能否使用：电压、插头、网络、语言、气候、尺寸和无障碍需要。
3. 售后：谁负责保修、送修地点、运费、等待时间、零件及软件支持。
4. 权利：退货、退款、自动续费、维修和跨境交易适用规则。
5. 替代资源：当地公共交通、图书馆、公共医疗及其他可用服务。
6. 个人负担：当地收入、照护责任、住房空间和必要付款义务。

## 本书不采用的全球化推断

- 不把美国退款提醒写成全球退款权。
- 不把欧盟立法公告写成每个国家已经实际实施。
- 不把温带地区的衣物和居住经验套进热带。
- 不把高收入样本的“便宜”当成所有人的低负担。
- 不把英语网络社区的热门意见称为全球共识。
- 不把健康行为有益推导成昂贵健康商品值得买。
