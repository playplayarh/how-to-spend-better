## 对首版的判断

优点是成本、收益、方法与边界清楚，能直接在GitHub阅读。主要不足是具体场景少，方法占多数；地区与货币写法偏向本地；资料没有充分解释体验、关系与省时消费的条件；家电计算没有充分区分“本来要换”与“旧机仍可用”。

## 用于优化的长期依据

1. [S08：资源条件与消费快乐](https://www.psychologicalscience.org/journals/psychological-science/0956797617736386/)：修订第26条，避免把体验消费排成对所有人都优先。
2. [S09：体验结果好坏](https://academic.oup.com/jcr/article/36/2/188/1942750)：补上退改、失败情境与体验不合适的可能。
3. [S10：共同参与的情境](https://pubmed.ncbi.nlm.nih.gov/23276272/)：第27条保留意愿与陪伴，不把快乐归因于消费类别本身。
4. [S11：欧盟维修立法说明](https://www.consilium.europa.eu/en/press/press-releases/2024/05/30/circular-economy-council-gives-final-approval-to-right-to-repair-directive/)：第23条说明维修制度有地区边界，不声称全球权利相同。
5. [S12：花钱省时](https://pmc.ncbi.nlm.nih.gov/articles/PMC5559044/)：第21条区分调查关联与短期实验，不把省时一概转成收入或长期幸福。

上列资料发布于2009—2024年，不包装为近30天新研究。详细核对深度及边界见[来源记录](来源与核对范围.md)。
