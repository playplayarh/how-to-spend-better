# 编写原则

1. 每条从具体问题开始，解释付出与可能得到的改善。
2. 官方资料只用于其直接支持的范围。行为有健康益处，不等于相关商品值得购买。
3. 数字写清单位、时间、地区和假设；商品价格若未查证，明确标为虚构演示。
4. 方法建议不伪装成实验结论；不使用任意的科学证据评级。
5. 同时说明适合的情境、不适合的情境和低成本替代办法。
6. 不按单一品牌推荐，不设推广链接，不收集个人消费或健康数据。
7. 个人愉悦、休息与关系可以成为消费理由，不要求每笔钱产生收入。
8. 健康、资格、法律与安全要求优先于节省费用。不要用一般建议替代专业判断。
9. 新增条目需有独立用途，避免为凑数量重复同一建议。
10. 修正重要事实时保留更新说明，同时检查来源记录与关联条目。

## 新条目模板

- 标题：动词开头，指向一个具体行动。
- 依据类型：资料／算账／方法，可组合。
- 花费：钱、时间、维护与机会成本。
- 换回什么／判断要点：不夸大、不保证。
- 怎么做：尽量给可执行的小步骤。
- 适用边界：不适合谁，哪些条件会改变结论。
- 来源：直接页面、来源日期、核对日期、支持的具体陈述；无外部依据则明说。
