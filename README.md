# 高性价比投入指南

把有限的钱，花在能让生活持续变好的地方。

讲生活中的钱怎样花才值得：睡眠和运动怎么安排，课程怎么买，工具什么时候升级，住得近一点值不值，哪些工作值得请人做，也讲兴趣与休息怎样花得安心。

一笔钱的价值，要连同使用次数、后续费用、维护时间和替代办法一起看。享受本身也有价值，不必把每次消费都解释成赚钱或提升效率。

**v0.2.0 · 2026-10-30 · 8章32条。** 全球视角中文修订版，面向普通成年读者；算例以同一种货币单位演示，未提供实时商品报价或购买力比较。可直接在 GitHub 阅读，无需安装或部署。

## 先从眼前的支出开始

打开[消费速查表](docs/先看这张消费速查表.md)，按睡眠用品、课程、电脑、家电、服务或旅行找到入口。每行都写了值得加钱的条件、可以先不买的条件和最小下一步。

本书关注你已经遇到的问题，也允许负担得起的享受。它不要求把生活全部优化成最低支出，不把贵价、耐用或体验消费自动视为更好。

## 只想先用一个方法

挑一笔正在犹豫的支出，填一张[购买判断卡](docs/购买判断卡.md)。写清原本的问题、整个使用期间的成本、预期使用次数和不买的办法。确定它负担得起，再比较是否值得。

预算有限时，可以先处理必要的健康、安全与基本生活需要，再考虑持续影响生活的具体不便，最后安排可负担的升级和享受。这只是起点，不是适用于所有人的统一排名；紧急程度和个人责任会改变顺序。

## 每条建议怎么看

- **花费**：钱、时间，以及持续维护的负担。
- **换回什么／判断要点**：可能得到的改善，或需要比较的关系。
- **怎么做**：能开始执行的小步骤。
- **适用边界**：哪些情况不能照搬。
- **来源**：有资料的明确链接；没有实证支持的方法直接说明。

全文使用三种依据标签，可以组合：

| 标签 | 含义 | 不能据此声称什么 |
| --- | --- | --- |
| 资料 | 已核对官方资料或研究发布方的摘要，见来源记录 | 不代表每个品牌、每个人都有相同效果 |
| 算账 | 数学关系与明确假设下的演示 | 不代表真实报价或保证回报 |
| 方法 | 本文提出的决策、沟通或观察方法 | 不包装成研究证实的最佳做法 |

这些标签不是证据强弱评级。第05、06、07、10、16、18、19、21、23、26、27条关联外部资料；其余21条是方法或算账建议。不宣称所有条目均有科学研究支持，也不使用缺少统一尺度的“性价比分数”。
